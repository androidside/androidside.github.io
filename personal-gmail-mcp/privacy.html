Privacy policy

Personal Gmail MCP collects nothing, stores nothing remotely, and shares nothing with anyone.

The short version

This application has one user, its author, and runs entirely on that person's own computer. There is no server, no database, no hosting, no analytics, and no third party. Nobody else's data passes through it, because nobody else uses it.

What it accesses

It requests exactly one Google permission: https://www.googleapis.com/auth/gmail.readonly. That grants read access to the signed-in account's mail. It requests nothing else, and it refuses to start if Google grants any other permission.

Where the data goes

Mail content travels between Google's servers and the one computer running the application. It goes nowhere else. The application keeps no cache, no search index, and no log of messages, subjects, or senders. When it finishes answering a question, it retains nothing.

Content it retrieves does appear in the AI assistant session that asked for it, and that assistant handles it under its own provider's terms. An attachment is written to the local disk only when the user explicitly asks for that file.

Credentials

The Google refresh token and OAuth client details are stored in a private directory on the same computer, readable only by that user account. They are never transmitted anywhere except to Google, and never appear in logs or error messages.

Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is used only to answer the user's own direct requests. It is never transferred to anyone, never used for advertising, never sold, and never used to train any model.

Withdrawing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops the application working immediately. Deleting the local directory removes the stored credentials.

Contact

This application has a single user, who is also its author. There is no other user base to support, so no contact address is published here.
