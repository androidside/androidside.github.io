Personal Gmail MCP

A private tool that lets an AI coding assistant read one person's Gmail. Read-only, running on that person's own computer.

What it does

It connects a local AI assistant to a single Gmail account so the assistant can search and read mail when asked to. It runs as a small program on one laptop. There is no website to sign up for and no service behind it.

What it cannot do

It holds one Google permission, gmail.readonly. It cannot send, reply, forward, delete, archive, label, or change anything at all. No code for writing to Gmail exists in it.

Who can use it

One person: its author. It is not published, not distributed, and not offered to anyone else. If you have arrived here from a Google consent screen and you are not that person, you should not grant it access.
