# Browser icons

These unmodified SVGs come from [Browser Logos 75.0.1](https://github.com/alrra/browser-logos/tree/75.0.1):

- [Firefox](https://github.com/alrra/browser-logos/blob/75.0.1/src/firefox/firefox.svg), a Mozilla trademark.
- [Microsoft Edge](https://github.com/alrra/browser-logos/blob/75.0.1/src/edge/edge.svg), a Microsoft trademark.

The logos identify the browsers used for the dashboard accounts. Logos and trademarks belong to their respective owners, as stated in the source project's [legal notice](https://github.com/alrra/browser-logos/tree/75.0.1#legal).
