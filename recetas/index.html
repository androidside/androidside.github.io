IMPORT WALKTHROUGH

A scan becomes a recipe

  1. Keep the original. Import a PDF or a photo, including handwritten notes.
  2. Group the pages. Match the recipe titles and leave blank pages out. Pomegranate bites uses two full pages.
  3. Read and review. OCR extracts text. Compare quantities and handwriting with the scan.
  4. Save the ingredients. The recipe keeps its ingredients, notes and product choices for next time.

This library contains the imported recipes. It does not upload files or run OCR.
